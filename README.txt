TRÊS ESTAÇÕES — DEMONSTRAÇÃO CONCEPTUAL

Ficheiros incluídos:
- index.html: estrutura e conteúdo da página
- estilos.css: design, cores, responsividade e animações
- script.js: introdução cinematográfica e interações
- README.txt: estas instruções

PUBLICAÇÃO NA NETLIFY
1. Descompacta este ZIP.
2. Adiciona os quatro ficheiros à raiz do repositório GitHub tres-estacoes-demo.
3. Na Netlify, importa esse repositório.
4. Para este site estático, não é necessário comando de build nem diretório de publicação especial.
5. Abre o endereço publicado e testa no telemóvel e no computador.

IMPORTANTE
Este é um conceito visual independente, não um site oficial do restaurante.
Não inclui fotografias reais, preços, menu confirmado ou contactos comerciais.
Pede autorização antes de usar publicamente os elementos oficiais da marca.

O Google Fonts é carregado pela Internet; se falhar, o site usa fontes alternativas.
O código foi preparado para site estático, mas testa a publicação real antes de afirmar que tudo funciona em todos os dispositivos.
